# FedG-XD (Initial Draft)

FedG-XD is a UAV network security project focused on graph-based intrusion detection and federated learning.

## Dataset

The project uses the ISOT Drone Dataset.

The dataset is stored separately from this repository because of its large size.

## Project Pipeline

ISOT Drone Dataset
        ↓
Data Preprocessing
        ↓
Feature Alignment
        ↓
Graph Construction
        ↓
GraphSAGE
        ↓
Federated Learning
        ↓
Cross-Domain Evaluation
        ↓
Attack Detection
